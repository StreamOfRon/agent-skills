# PEP 723: Inline Script Metadata

PEP 723 defines a way to embed dependency metadata directly in Python scripts using TOML-formatted comments.

## Format

The metadata block must:
- Start with `# /// script`
- End with `# ///`
- Contain valid TOML between the markers
- Each line prefixed with `# ` (hash + space)

## Example

```python
# /// script
# requires-python = ">=3.11"
# dependencies = [
#     "requests<3",
#     "rich",
# ]
# ///
```

## Supported Fields

- `requires-python`: Python version constraint
- `dependencies`: List of PEP 508 dependency specifiers
- Additional fields from PEP 621 may be supported by tools

## Tools

- **uv**: Supports PEP 723 natively via `uv run --script`
- **pip**: Does not support inline metadata directly
- **Other tools**: Check tool documentation for PEP 723 support
